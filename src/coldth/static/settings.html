Artwork enabled here but not appearing?

Shairport must also request it. In /etc/shairport-sync.conf, merge these values into the existing metadata section—do not put include_cover_art at the top level: 

metadata = {
    enabled = "yes";
    include_cover_art = "yes";
    pipe_name = "/tmp/shairport-sync-metadata";
};

Then restart Shairport and reconnect AirPlay:

sudo systemctl restart shairport-sync

To stop requesting artwork, change include_cover_art back to "no" and restart Shairport.

Coldth does not contact a music database or artwork service. It only accepts information included in the local AirPlay stream. Shairport must separately be configured to request artwork; the Coldth installer leaves that off by default.
